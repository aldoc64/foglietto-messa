Aggiornare la tabella su AirTable.

https://foglietto-messa.vercel.app/

Dal browser dello smartphone cliccare sui tre puntini verticali e selezionare "Aggiungi a schermata Home". Poi quando si clicca sull'icona della app questa verrà aperta senza mostrare la barra degli indirizzi del browser.

Se si apre il link con Chrome viene chiesto se si vuole installare la app, e se la si installa viene inserita tra le app, senza l'iconcina del browser sotto.
